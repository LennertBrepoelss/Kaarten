# Kaartavond

Troeven, wiezen en hartenjagen op café, met de afrekening van de rondjes.

## Online zetten (gratis, GitHub Pages)
1. Zet alle bestanden uit deze map in de hoofdmap van een **publieke** repository, bijvoorbeeld `kaartavond`.
2. Ga in de repository naar **Settings → Pages**.
3. Kies bij *Source* **Deploy from a branch**, branch **main**, map **/ (root)**, en klik **Save**.
4. Na een minuut staat de app op `https://<jouw-naam>.github.io/kaartavond/`.

## Op je telefoon zetten
- **Android (Chrome):** open de link, tik op ⋮ en kies **App installeren** of **Toevoegen aan startscherm**.
- **iPhone (Safari):** open de link, tik op Deel en kies **Zet op beginscherm**.

## Updates
Bij elke nieuwe versie verandert `version.json`. De app kijkt elke 20 seconden en telkens je ze opent.
Staat je op een rustig scherm, dan laadt ze vanzelf opnieuw. Ben je iets aan het ingeven, dan wacht ze tot je klaar bent.

## Gegevens
De app bewaart alles op de telefoon zelf. Wis je de gegevens van de browser of de app, dan zijn ze weg.
